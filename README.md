# 🎓 EduFlow AI — Enterprise Curriculum & Course Intelligence Platform

> Powered by **Next.js 16 (Turbopack)**, **Auth.js v5**, **Prisma v7**, **Tailwind CSS v4**, and **Google Gemini 2.0 Flash AI**.

Designed and Architected by **Shivam Kumar**.

---

## 🌟 Key Features

- ⚡ **Gemini 2.0 Flash Assistant** — Floating AI chat drawer for real-time curriculum advice, Bloom's Taxonomy learning objectives, and quiz generation.
- 📊 **Executive Analytics Dashboard** — Real-time metrics, interactive Recharts visualizations, reviewer workload, and author productivity trackers.
- 🎯 **AI Quality Audit Engine** — Instant course health scoring, structural checks, Bloom's coverage analysis, and actionable quality recommendations.
- 🔄 **Approval Workflow Stepper** — Full 4-tier approval pipeline (Draft ➔ ID Audit ➔ Peer Review ➔ Admin Sign-off).
- 🧬 **Curriculum Analyzer & Duplicate Detection** — Automated graph-based module analysis and semantic duplicate lesson detection.
- 🛡️ **Enterprise Security & Auth** — Role-Based Access Control (RBAC), Auth.js v5 with JWT session handling, and OWASP security headers.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 App Router (Turbopack)
- **Styling**: Tailwind CSS v4 + Glassmorphic Design System
- **Database**: PostgreSQL (Prisma ORM v7)
- **AI Core**: `@google/genai` (Gemini 2.0 Flash)
- **Authentication**: Auth.js v5 (NextAuth)
- **Testing**: Vitest & Playwright E2E

## 💻 Getting Started

```bash
# Clone the repository
git clone https://github.com/Chivvu/edtech-app.git
cd edtech-app

# Install dependencies
npm install

# Run database migrations & seed
npx prisma db push
npx prisma db seed

# Start development server
npm run dev
```
